# 内置 PPT 模板

`catalog.json` 是六套内置模板的唯一目录，前端在线预览和后端 PPTX Renderer 共同读取其中的颜色、字体和构图策略。运行时 Renderer 根据页面 Schema 确定性创建封面、目标、情境、概念、流程、练习和总结页；不把逐字稿塞入课件。

旧课件缺少模板标识或模板已失效时，统一回退到 `lessonforge_swiss_blue`。

目录中的 6 份同名 `.pptx` 是可直接打开和编辑的模板样稿。每份包含封面、目标列表、左右分栏、步骤流程、课堂练习和总结 6 类页面，并使用统一的“阿基米德原理”内容方便老师横向比较视觉风格。`catalog.json` 的 `file` 字段记录对应文件名。
